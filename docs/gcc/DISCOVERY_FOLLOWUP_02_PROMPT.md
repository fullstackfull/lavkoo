### 7. GCC-20 — تدقيق إضافي إلزامي لتطبيق البائع
المالك يريد داخل `lavkooappseller` وضع **Super Admin خاص بالمنصة** يراقب كل الدول الست، مع شاشة جميع الأسواق ودخول لكل دولة، ووظائف مستقلة عن البائع العادي.
- اقرأ وثيقة `docs/gcc/GCC-20-SUPER-ADMIN-MOBILE.md`.
- افحص `AdminMiddleware` وadmin guard وأدوار الإدارة، و`SellerApiAuthMiddleware` وSellerPrincipal وSellerStaff وSeller API v3، وتطبيق البائع AuthController/ControlTower/Dashboard/Menu.
- وثّق الفرق الأمني بين platform admin وseller/staff: **ممنوع استخدام seller token أو client-side flag لفتح صلاحية Super Admin**.
- اقترح فقط عقد مصادقة Admin Mobile محميّاً في Backend، فصل التنقل والقوائم، أمان التنقل بين الدول وعزل الكاش/FCM، مراقبة مجاميع الأسواق حسب الشركة والعملة، وسجلات التدقيق ومراجعة العمليات الحساسة.
- حدد خطة مراحل `monitoring read-only → limited operations → sensitive actions with extra approval`، مع test matrix لإثبات منع التسرب ورفع الصلاحيات.
- لا تكتب API أو UI ولا تغير auth فعلياً.
